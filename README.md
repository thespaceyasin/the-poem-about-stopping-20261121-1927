make.fun bounty

The program writes one poem to `/output/entry.txt`.

## The poem

```
The sewing machine hums on.
My foot is still on the pedal
when I lift it.
The needle stops above the cloth,
half a stitch from done.
My grandmother's scarf waits,
one loose thread in my hand.
I do not finish it.
I keep the place she stopped.
```

241 characters, inside the 1 to 280 limit.

## Run

```sh
node main.ts
```

Or with an explicit output directory:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

Node 22, standard library only, deterministic, no network.
